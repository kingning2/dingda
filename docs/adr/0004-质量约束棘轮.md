# ADR-0004：质量约束写进 CONSTRAINTS.md 并以守卫棘轮化

状态：采纳 · 日期：2026-02-14（030bb9ed）

## 背景

CI 已有四道门禁（tsc、ruff、vitest、pytest），但三类问题无防护：
① agent 生成代码时悄悄加 `@ts-ignore` / `# noqa` / 删测试断言来"修绿"；
② 覆盖率、依赖漏洞、产物体积这些数字没人记录，也就没人发现它们在恶化；
③ 分层规则只在 AGENTS.md 散文里，agent 读完未必照做。

## 决策

1. **地板规则**（零成本、永远阻断）：禁新增静音注释、禁半成品
   （空 catch / `except Exception: pass` / TODO）、禁跳过或删测试、禁泄密钥。
   由 diff 域守卫 `scripts/check/floor-guard.mjs` 强制（退出码 0/1/2，
   改自 agent-skills 的 MIT 参考实现，见 `.agents/references/LICENSE-agent-skills`）。
2. **分层机械子集**：`scripts/check/layers-guard.mjs`（规则见 ADR-0003）。
3. **棘轮代替拍脑袋**：覆盖率 / 漏洞数 / 产物体积记录实测值于 CONSTRAINTS.md，
   方向锁死（只许变好）；目标值（如变更行覆盖 ≥ 80%）等基线稳了再定。
4. **策略**：地板与既有门禁阻断；新检查（layers、gitleaks、audit）观察期两周
   警告，无误报后转阻断；例外只能进 CONSTRAINTS.md 例外表（带负责人与过期日）。

当日基线（2026-02-14）：FE Lines 100% / Branches 91.28%；PY 64%；
audit 24 项（9 high / 1 critical）；dist JS ≈ 998 kB。

## 后果

- `pnpm check:fast`（< 5s）进编辑循环；更慢的检查只进 CI。
- 放宽约束的动作会被 floor-guard 在 diff 里点名；收紧永远静默放行。
- 待办：CI 接 `cargo test --workspace`（Rust 已有 `#[cfg(test)]` 但门禁未跑）。
